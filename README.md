# Smart Bookmark CRUD Application

## 📌 Project Overview
This is a full-stack Bookmark Manager built using Django and Django REST Framework.

The application allows users to:
- Add bookmarks
- View all bookmarks
- Update bookmarks
- Delete bookmarks
- Search bookmarks instantly

---

## 🛠 Tech Stack

- Backend: Django
- API: Django REST Framework
- Database: SQLite
- Frontend: HTML, Bootstrap, JavaScript
- Version Control: Git & GitHub

---

## 🚀 Features

- Full CRUD functionality
- Modern responsive UI
- Toast notifications
- Edit mode inside form
- Live search filter
- Clean and professional design

---
